## 6. 需要确认的问题

> 本节只记录**从原理图看出来的硬件事实**。对应的**固件规避方案**统一在
> `云台固件架构设计.md` 附录 B（B1–B12），那里是方案的唯一出处，本节不重复。

### 6-1 线束引脚顺序不一致（装配风险）

40P 侧电机组顺序为 `+3.3V / GND / 霍尔 / 相×6`，而 BOD12-11 的 J1 顺序为 `相×6 / 霍尔×2 / GND / VIN`。
两端顺序相反，**线束必须交叉**。若误做 1:1 直通线，J2-11 的 +3.3V 会直接落到电机相线上，通电即短路。建议在线束上做防呆（不同颜色/键位）。

→ 固件侧无解，见附录 B **B.11**。

### 6-2 PA6 复用

PA6 同时连接 `R15 100R → J3-5（PWM1）` 和 `R4 4.7K → Q1（MMBT3904）基极`，Q1 集电极经 R3 10K 上拉至 +3.3V 并由 PC11 读取。
需确认：PWM1 是输入（接收机）还是输出（相机控制）？若为输入，Q1 基极由外部信号驱动，存在误触发风险。

→ 两种确认结果对应的配法见附录 B **B.12**。

### 6-3 nFAULT 全部悬空

三路驱动芯片的 nFAULT（pin 20）均未连接，过流/过温时 MCU 无感知。建议用三只二极管线与后接一个 GPIO。

→ 见附录 B **B2**。

### 6-4 无电流采样

LSS 直接接地，SA/SB/SC 直连电机，全板无采样电阻，只能做电压模式 FOC。若后续要加电流环，可用 PC0/PC3 两路空闲 ADC + 外部运放，但需要改驱动芯片（本芯片不提供电流输出）。

→ 见附录 B **B1**。

### 6-5 母线电压采样超量程

**走线已核实**（PDF 矢量路径连通域追踪）：`+7V → R8 49.9K → 节点(带 C51 100nF 到 GND) → R6 49.9K → GND`，节点直连 **PC0（pin 8，ADC123_IN10）**。

- 分压比 1/2，7.2 V 母线 → **3.6 V**，超过 3.3 V 满量程，ADC 读数恒为 4095。
- 输入电流约 72 µA（(3.6−3.3)/24.95K），经引脚钳位二极管泄放到 VDDA，在规格内（钳位限值 ±5 mA），**不会损坏**，但这一路**测不到工作点电压**。
- 修正方案本应是 R8/R6 改 49.9K/24.9K（满量程约 9.9 V）。**当前硬件已冻结，不改板。**

→ 三件事的可行性（前馈 ❌ / 过压 ❌ / 欠压 ✅）与 `valid` 标志的实现细节见附录 B **B3 专项**。

### 6-6 烧录方式

BOOT0 固定接地，PA9/PA10 已作电机 2 的 PWM，无法使用 UART ISP；板上无 USB。**只能通过 SWD 烧录**，量产需要治具或增加测试点阵列。

→ 见附录 B **B9**。

## 1. 系统组成

四块板，通过 40P FPC 一分四连接。

| 板 | 型号 | 数量 | 核心器件 | 作用 |
|---|---|---|---|---|
| 主控板 | IUO112 | 1 | STM32F405RGT6 + 3× SS6343M | MCU、三路电机驱动、电源、对外接口 |
| 电机端板 | BOD12-11 | 3 | 2× MT9101ET | 线性霍尔、电机三相接口 |
| IMU 板 | R14AQ | 1 | ICM-42688-P + DS8242-33S3 | 六轴 IMU、加热恒温 |
| — | 40P FPC | 1 | DF56C-40S-0.3V(51) | 主板到四块子板的唯一通道 |

**关键事实：所有功率和信号都从主板出，子板上没有任何主动器件（除了 IMU 板的一颗 LDO 和一颗加热 MOS）。**

**单路驱动通道的信号流**（三条完全相同）：

```
MCU ──PWM A/B/C──► SS6343M ──SA/SB/SC──► FPC ──► BOD12-11 ──A/B/C──► 电机绕组

        └─ nSLEEP                                    └─ 2× MT9101ET
                                                          │
                     ADC ◄── FPC ◄── OUT_L / OUT ◄────────┘
```

**注意**：霍尔信号和相线走同一根 FPC，这是后面所有噪声问题的根源（见 §7 与附录 B B7）。

## 3. 电源树

```
J3-1  VDD ──► TVS D1 (JEB36D5P) ──► SY8303AAIC ──► +7V (7.2V)
                                        │              │
                              R39 110K / R40 10K        │
                              (FB 分压，Vref 0.6V)      │
                                                       ├──► U1/U2/U3 的 VIN（电机母线）
                                                       ├──► 40P pin 9–10 → IMU 板 VIN
                                                       ├──► J1 (2P) → 7V 对外输出
                                                       └──► AMS1117-3.3 ──► +3.3V
                                                                                │
                                                                                ├──► MCU
                                                                                ├──► 40P 各组 → 6× MT9101ET
                                                                                └──► 上拉/参考
```

| 节点 | 电压 | 来源 | 负载 |
|---|---|---|---|
| **VDD** | 外部输入 | J3-1 | SY8303 输入 |
| **+7V** | **7.2 V** | SY8303 同步降压（L1 2.2 µH，C34/C35 22 µF） | 三路电机、IMU 加热、对外 7V |
| **+3.3V** | 3.3 V | AMS1117-3.3（SOT-89） | MCU、6 路霍尔 |
| **IMU 3.3V** | 3.3 V | **IMU 板本地 DS8242-33S3**（从 +7V 转） | ICM-42688-P |

**三个要点**

1. **IMU 板不用主板的 3.3V。** 40P 的 IMU 组（pin 1–10）只送 +7V，不送 +3.3V。IMU 板自己用 DS8242-33S3 从 7V 降到 3.3V。这是对的——避免长线压降和电机噪声耦合到 IMU 供电。

2. **AMS1117 压差 3.9 V。** 7.2 V 进、3.3 V 出，耗散 = 3.9 × I_load。SOT-89 热阻约 60–100 °C/W，200 mA 负载时耗散 0.78 W，温升可达 50–80 °C。这是板上最热的器件之一（附录 B B5）。

3. **SS6343M 自己还有一路 3.3V LDO（V3P3，100 mA）**，只给内部栅极驱动用，不对外供电。旁路要求 4.7–10 µF，实际 2.2 µF（附录 B B8）。

## 4. 主控板 IUO112

### 4.1 器件清单

| 位号 | 型号 | 作用 | 关键参数 |
|---|---|---|---|
| **U4** | **STM32F405RGT6** | 主控 MCU | LQFP-64，168 MHz，1 MB Flash，192 KB RAM，FPU |
| **U1/U2/U3** | **SS6343M-QF-TP** | 三相电机驱动 ×3 | 16 V / 2 A，6× N-MOS 70 mΩ，QFN3×4-24L |
| U5 | AMS1117-3.3 | 3.3 V 线性稳压 | SOT-89，压差 3.9 V |
| U6 | SY8303AAIC | 同步降压 | VDD → 7.2 V，L1 2.2 µH |
| Y1 | XL7EL89CKI-111YLC-16M | HSE 晶振 | 16 MHz，C5/C6 6.8 pF，R9 1 M |
| Q1 | MMBT3904 | NPN，状态回读 | 基极经 R4 4.7K 接 PA6，集电极经 R3 10K 上拉由 PC11 读 |
| D1 | JEB36D5P | 输入 TVS | 唯一一颗，无反接保护 |
| J2 | DF56C-40S-0.3V(51) | 40P FPC 内部总线 | 0.3 mm 间距 |
| J3 | ZX-SH1.0-8PLT | 主机接口 | VDD / GND / UART2 / PWM1–4 |
| J4 | ZX-SH1.0-3PLT | 调试串口 | UART5（TX5 / RX5 / GND） |
| J1 | ZX-SH1.0-2PLT | 7V 输出 | 给相机或图传 |
| J5–J8 | 单针 | 测试焊盘 | 悬空 |

### 4.2 三轴驱动通道

三个 SS6343M 的接法完全一致，只有引脚分配不同。

> **三轴的 PWM 通道顺序各不相同**：M1 是倒序（TIM4_CH3/CH2/CH1），M2 是正序（TIM1_CH1/2/3），
> M3 从 CH4 起（TIM3_CH4/3/2）。这是布线的结果，固件必须用表驱动，不能假设顺序一致。
>
> 逐引脚的完整映射（含 nSLEEP、霍尔 A/B、每相 2 pin 的 J2 引脚号）见
> `IUO112_引脚配置清单.md` §3「电机驱动分配」，此处不重复。

**SS6343M 的控制特性（规格书确认）**

| 项 | 说明 |
|---|---|
| 接口 | ENBL + PWM，**每相一个 PWM**，内部自动生成互补信号和 40 ns 死区 |
| 输出能力 | 2 A 持续（取决于温度和 PCB），过流保护峰值 7 A |
| 电荷泵 | 支持 **100% 占空比**运行 |
| 保护 | 过温关断、UVLO、OCP —— 但 **nFAULT 未引出到 MCU** |
| EN 接法 | 三路 EN 并接、经 4.99K 上拉到 3.3V → **常使能，无法单相关断** |
| LSS | 直接接地，**无采样电阻** |

### 4.3 对外接口

四个连接器的分工：**J3 = 主机接口（VDD/GND + USART2 + PWM1–4）、J4 = 调试串口（UART5）、J1 = 7V 输出、J2 = 40P FPC 内部总线**。

逐引脚的连接器定义见 `IUO112_引脚配置清单.md` §4「对外接口」，此处不重复。

## 5. 电机端板 BOD12-11（×3）

结构极简：一颗 10P 连接器、一颗 3P 电机连接器、两颗线性霍尔。

### 5.1 器件

| 位号 | 型号 | 作用 |
|---|---|---|
| J1 | 0.4 mm 间距 10P 板端连接器 | 接主板 FPC |
| J2 | 3P | 接电机三相 A/B/C |
| U1/U2 | MT9101ET | 线性（模拟）霍尔，输出 Vcc/2 + S·B |
| C1/C3 | 100 nF | 霍尔电源旁路 |
| C2/C4 | 4.7 nF | 霍尔输出 RC 滤波 |
| C5 | NC | 未贴 |

### 5.2 J1 引脚

| 引脚 | 网络 | 说明 |
|---|---|---|
| 1–2 | c | C 相（2 pin 并联） |
| 3–4 | e | B 相 |
| 5–6 | V | A 相 |
| 7 | OUT_L | 霍尔 1 输出 |
| 8 | OUT | 霍尔 2 输出 |
| 9 | GND | — |
| 10 | VIN | 3.3 V（霍尔供电） |

> **相线每相只有 2 个引脚**。DF56 系列 0.3 mm 间距的载流能力需要按实际相电流核对（附录 B B4）。

### 5.3 霍尔电路

- 两颗 MT9101ET 在板上按 **90° 或 120°** 机械分布（**按 120° 设计，待 W1 实测确认**；判定方法与状态见 `云台固件架构设计.md` §2 第 1、3 项）
- 输出为**模拟电压**，不是开关量。一个电周期内连续变化，配合 atan2 可解出绝对角度
- 每颗配 100 nF 旁路 + 4.7 nF 输出滤波
- **信号线上没有串阻**，直接进 FPC（附录 B B7）

## 6. IMU 板 R14AQ

### 6.1 器件

| 位号 | 型号 | 作用 |
|---|---|---|
| **U2** | **ICM-42688-P** | 六轴 IMU（3 轴陀螺 + 3 轴加速度） |
| U1 | DS8242-33S3 | 3.3 V LDO，VIN(7V) → 3.3 V |
| Q1 | 3400L | N-MOS，加热低边开关 |
| R4–R11 | 2 Ω × 8 | 串联 16 Ω，加热电阻 |
| R2 / R3 | 1 K / 1 K | Q1 栅极分压 |
| J1 | 20374-R10E-31（10P） | 接主板 FPC |
| C7 / C6 | 2.2 µF / 100 nF | 3.3 V 旁路 |

### 6.2 IMU 引脚连接

| 引脚 | 名称 | 连接 |
|---|---|---|
| 1 | AP_SDO / AP_AD0 | → AP_SDO（SPI 的 SDO） |
| 2, 3 | RESV | NC |
| 4 | INT1 / INT | **悬空** |
| 5 | VDDIO | +3.3 V |
| 6 | GND | GND |
| 7 | RESV | — |
| 8 | VDD | +3.3 V |
| 9 | INT2 / FSYNC / CLKIN | **悬空** |
| 10 | RESV | NC |
| 11 | RESV | GND |
| 12 | AP_CS | → AP_CS（片选） |
| 13 | AP_SCL / AP_SCLK | → AP_SCL（时钟） |
| 14 | AP_SDA / AP_SDIO / AP_SDI | → AP_SDA（SDI） |

**两个直接决定固件写法的结论**

1. **4 线 SPI**（CS / SCLK / SDI / SDO 齐全），用标准全双工，不需要半双工折腾。
2. **INT1 和 INT2 都悬空** → IMU 只能轮询，**控制时基必须由定时器决定**，不能靠数据就绪中断触发。

### 6.3 加热回路

```
+7V ──► R4 ─► R5 ─► R6 ─► R7 ─► R8 ─► R9 ─► R10 ─► R11 ──► Q1(D) ──► Q1(S) ──► GND
 (2Ω)  (2Ω)  (2Ω)  (2Ω)  (2Ω)  (2Ω)  (2Ω)  (2Ω)              │
                                                               │
        PC6 ──► R2 1K ──┬──► Q1(G)                            │
                        │                                      │
                       R3 1K                                    │
                        │                                      │
                       GND                                     ▼
```

| 项 | 值 | 说明 |
|---|---|---|
| 加热电阻 | 8 × 2 Ω 串联 = **16 Ω** | 分布在 IMU 周围 |
| 供电 | **+7V**（不是 3.3V） | 从 FPC 进来 |
| 理论功率 | 7² / 16 ≈ **3.1 W** | 全导通时 |
| 栅极电压 | 3.3 × 1K/(1K+1K) = **1.65 V** | ⚠ 见下 |
| 控制信号 | PC6（主板）→ FPC → J1-10 | 高电平加热 |

> ⚠ **栅极只有 1.65 V**，对 3400L 这类 MOS 处于临界导通区，实际电流会明显小于 437 mA，加热功率可能只有 1~1.5 W。板子已冻结无法改，固件对策：`thermal.c` 的 PI 输出**直接给满**，不要指望靠占空比精细调节；同时要有"设定温度长期达不到"的降级逻辑。

## 8. 硬件对固件的硬约束（索引）

这张表是"硬件逼着软件必须这么做"的清单，详细展开在 `云台固件架构设计.md` 附录 B。

| 硬件事实 | 固件必须怎么做 |
|---|---|
| 无相电流采样 | 只能电压模式 FOC：位置 → 速度 → 电压，靠反电动势前馈补动态 |
| nFAULT 悬空 | 保护只能靠"指令饱和 + 角度不跟随"判堵转 |
| 母线分压超量程 | `vbus` 传常量；该通道只做欠压判别（<6.6 V） |
| 霍尔是绝对角度 | 上电即知位置，不需要预定位/开环强拖，状态机可大幅简化 |
| IMU 无中断引脚 | 只能轮询，控制时基必须由定时器决定 |
| 霍尔线无 RC | 滤波必须做成可调参数，陷波是必需项不是优化项 |
| EN 全部上拉 | 只能整片 nSLEEP，不能单相关断 |
| 加热栅极仅 1.65 V | 加热 PI 输出给满，不做精细占空比调节 |
| 只能 SWD 烧录 | 调试阶段务必保留 SWD 排针，别封进结构件 |

## 9. 已知问题

完整的 12 项问题与规避方案见 `云台固件架构设计.md` **附录 B**。这里只列 P0 三项：

| # | 问题 | 后果 |
|---|---|---|
| **B1** | 无相电流采样（LSS 直接接地） | 做不了电流环，动态性能受限 |
| **B2** | 3 路 nFAULT 全部悬空 | 过流/过温后芯片自恢复 4 ms，MCU 无感知 |
| **B3** | 母线分压 1:2 超量程（7.2 V → 3.6 V > 3.3 V） | 测不到工作点电压，前馈和过压保护都做不了 |

### 装配注意

**40P FPC 与 BOD12-11 的 J1 引脚顺序相反**：

- 40P 侧：`+3.3V / GND / 霍尔 / 相 ×6`
- BOD12-11 侧：`相 ×6 / 霍尔 / GND / VIN`

**线束必须交叉。** 直连会把 3.3 V 直接落到相线上，上电即短路。建议在线束上做防呆。

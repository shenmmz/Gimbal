# FOC 技术栈

| 项 | 内容 |
|---|---|
| 适用 | 云台三轴无刷直驱（IUO112 + BOD12-11 ×3） |
| 驱动芯片 | SS6343M-QF-TP（集成栅极驱动 + 6× N-MOS 的三相功率级） |
| 版本 | v1.0（2026-10-26） |
| 与主文档关系 | 主文档《云台固件架构设计》讲"文件怎么放"，本文讲"信号怎么走" |

本文回答一个问题：**从霍尔的一路模拟电压，到三相桥臂的一次开关，中间到底要做哪些事。**

---

## 1. 先纠正一个接口认知

你说"PWM + 使能 IO 使能芯片"——**方向对了，但使能那根线不是你能控的。**

SS6343M 一颗就是完整的三相全桥（栅极驱动 + 6 颗 N-MOS + 电荷泵 + 过流保护），MCU 到它每轴只有 **4 根线**：

| 线 | 数量 | 方向 | 接法 | MCU 可控？ |
|---|---|---|---|---|
| PWMA / PWMB / PWMC | 3 | MCU → 驱动 | 各带 4.99K **下拉** | ✅ |
| nSLEEP | 1 | MCU → 驱动 | 带 4.99K **下拉** | ✅ |
| ENA / ENB / ENC | 3 | 驱动内部 | **三路并接，4.99K 上拉到 3.3V** | ❌ **摸不到** |

**EN 是硬件常使能的。** 三路 EN 并在一起上拉到 3.3 V，原理图上没有引到 MCU。所以固件里不要去找 EN 的 GPIO——它不存在。

真正能让芯片"安静下来"的是 **nSLEEP**：

| 引脚 | 各轴 | 有效电平 | 上电默认 |
|---|---|---|---|
| nSLEEP | 电机 1 → PC10<br>电机 2 → PA11<br>电机 3 → PA12 | **低 = 睡眠**（低有效） | **睡眠**（4.99K 下拉） |

由此得出三条固件铁律：

1. **上电默认是全睡着的。** 不拉高 nSLEEP，PWM 打进去也没反应。M1 阶段"PWM 没波形"或"电机不动"，第一个要查的就是这个。
2. **唤醒要等 1.5 ms。** 拉高 nSLEEP 后不能立刻给占空比，电荷泵和栅极驱动需要建立时间。`motor_enable()` 里必须有这一条。
3. **PWM 引脚有下拉，上电默认低电平。** 这是安全的——但意味着上电瞬间三相全关，电机是"自由"的，不是被短路刹住的。

开关时序必须严格按这个顺序：

```
上电        nSLEEP=L → PWM 全 0 → 配置定时器 → 等稳定
使能        PWM 保持 0 → nSLEEP=H → 等 1.5 ms → 允许输出占空比
关断        PWM 归 0 → 等 1 个 PWM 周期 → nSLEEP=L
```

关断时"PWM 归 0 再等一个周期"不能省——直接拉 nSLEEP 会让桥臂在占空比非零时突然失去驱动，残留电流走体二极管，虽然一般不炸，但会有一次反向尖峰打到母线上。

## 2. 技术栈全景

九层，自下而上。每层只依赖它下面那层，**任何一层出错，上面所有层都是废的**——这是调试必须从下往上逐层验证的原因。

| 层 | 名称 | 输入 | 输出 | 频率 | 文件 |
|---|---|---|---|---|---|
| L0 | 功率接口 | 占空比 0~1 | 桥臂开关 | 24 kHz | `driver/pwm.c` |
| L1 | 时间基准 | — | 8 kHz 硬触发 | — | `driver/pwm.c` |
| L2 | 采样 | 触发信号 | 7 路 ADC 原始值 | 8 kHz | `driver/adc.c` |
| L3 | 角度 | 2 路霍尔原始值 | 机械角 / 电角度 | 8 kHz | `algorithm/hall.c` |
| L4 | 速度 | 角度序列 | 角速度 | 8 kHz | `algorithm/hall.c` |
| L5 | 矢量合成 | uα / uβ | 3 路占空比 | 8 kHz | `algorithm/svpwm.c` |
| L6 | 串级控制 | 目标角 − 实际角 | uα / uβ | 8 kHz | `control/axis.c` |
| L7 | 前馈 | 角速度 / 角度 | 电压修正量 | 8 kHz | `control/feedforward.c` |
| L8 | 保护 | 全部状态 | 停机信号 | 1 kHz | `control/protect.c` |
| L9 | 标定 | 人工激励 | 参数 | 离线 | `algorithm/calibration.c` |

数据流是单向的，没有回环（除了 L6 的位置反馈）：

```
霍尔 ADC ──► L3 角度 ──► L6 位置环 ──► L6 速度环 ──► L5 SVPWM ──► L0 占空比
                │            ▲                            ▲
                └─► L4 速度 ─┘                            │
                                    L7 前馈 ─────────────┘
```

## 3. 逐层展开

### L0 功率接口

**做什么**：把 3 个 0~1 的占空比写进定时器 CCR，变成 3 路 24 kHz PWM。

**关键参数**：

| 项 | 值 | 怎么来的 |
|---|---|---|
| PWM 频率 | 24 kHz | 168 MHz / (ARR+1) = 168e6/7000，高于人耳上限，避开啸叫 |
| ARR | 6999 | 中心对齐模式，计数器 0→6999→0 |
| 计数模式 | 中心对齐 | 三相开关沿对称，谐波集中在 2×f_pwm，便于滤 |
| 死区 | **不设** | SS6343M 内部 40 ns，MCU 侧设了反而叠加 |
| 互补输出 | **不用** | 芯片内部生成互补，MCU 每相只给 1 路 |

**代码要点**：

```c
pwm_set_duty(uint8_t axis, const float duty[3]);   // duty 已在 [0,1] 内限幅
```

- 限幅必须在 L5 做完，L0 只负责写寄存器，不再判断
- 写 CCR 用预装载（`TIM_OCPreload_Enable`），保证三相同一个周期生效，避免中途改值产生窄脉冲

**坑**：三轴的 PWM 通道在定时器上的映射顺序是乱的（M1 用 TIM4_CH3/CH2/CH1 倒序，M2 用 TIM1_CH1/2/3 正序，M3 用 TIM3_CH4/CH3/CH2 倒序）。**必须用表驱动，不要按 CH1/CH2/CH3 想当然**，否则 M3 相序反了电机照样转，只是方向反——这种错最难查。

### L1 时间基准

**做什么**：产生一个严格等间隔的 8 kHz 硬触发，驱动整条控制链。

| 项 | 值 | 说明 |
|---|---|---|
| 主定时器 | TIM1 | 产生 TRGO |
| 从定时器 | TIM3 / TIM4 | 由 TIM1 TRGO 触发，三相同步启动 |
| 控制频率 | 8 kHz | PWM 24 kHz 每 3 个周期触发一次（RCR=2） |
| 周期 | 125 µs | 全部控制计算必须在这个窗口内完成 |
| 触发源 | TIM1 更新事件 → TRGO → ADC 外部触发 | 硬件直连，不经过软件 |

**为什么是 8 kHz 而不是 24 kHz**：云台的机械带宽只有 10~20 Hz，8 kHz 采样已经有 400 倍余量。提到 24 kHz 只会让 CPU 预算从 32% 涨到 96%，没有收益。

**为什么必须硬件触发**：如果用软件启动 ADC，触发时刻会随中断响应抖动（几个 µs），角度计算的 Δt 就不准，速度环会引入噪声。硬件触发让采样点相对开关沿恒定，噪声特性可重复。

### L2 采样

**做什么**：一次 DMA 搬完 7 路 ADC。

| 序号 | 通道 | 引脚 | 信号 | 用途 |
|---|---|---|---|---|
| 0 | IN0 | PA0 | M2 霍尔 A | 角度 |
| 1 | IN1 | PA1 | M2 霍尔 B | 角度 |
| 2 | IN11 | PC1 | M1 霍尔 A | 角度 |
| 3 | IN12 | PC2 | M1 霍尔 B | 角度 |
| 4 | IN14 | PC4 | M3 霍尔 A | 角度 |
| 5 | IN15 | PC5 | M3 霍尔 B | 角度 |
| 6 | IN10 | PC0 | 母线分压 | **仅欠压判别** |

**代码要点**：

```c
adc_get_raw(uint8_t axis, uint16_t buf[2]);   // 6 路霍尔，axis 内部查表映射
adc_get_vbus(uint16_t *raw, bool *valid);     // raw < 4000 才算有效
```

**坑一：母线通道是废的。** 分压比 1:2，7.2 V 分压后 3.6 V，超过 3.3 V 量程。6.6 V 以上读数全部饱和在 4095。所以它只能做欠压（< 6.6 V 时读数才有意义），不能做过压，也不能做前馈。

**坑二：采样时间。** 霍尔源阻抗低，采样时间给 15~28 cycles 就够；母线通道分压电阻 49.9K/49.9K，源阻抗高（约 25K），采样时间要给足 84~144 cycles，否则读数偏低。7 个通道采样时间不一样是允许的，ADC 每个通道可单独配。

### L3 角度

**做什么**：2 路模拟霍尔 → 归一化 → 120° 重构 → atan2 → 角度。

完整推导和磁环判别见主文档 §7.2.1，这里只列工程要点。

```c
float hall_decode(uint8_t axis, const uint16_t raw[2]);  // 返回弧度，−π~+π
```

**五步不能少**：

| 步 | 动作 | 漏了会怎样 |
|---|---|---|
| 1 | 各自减偏置 | 角度有 2θ 周期误差，典型 1~5° |
| 2 | 各自除增益 | 同上，且两路增益不等时误差更大 |
| 3 | `cosθ = −(vb + 0.5·va) × 1.1547005` | 直接 atan2(va,vb) 是 90° 公式，全错 |
| 4 | 乘 `hall_dir[axis]`（±1） | 转向反，位置环变正反馈 → 飞车 |
| 5 | 一阶低通 200~500 Hz | 开关噪声直接进速度环，嗡嗡响 |

**电角度与机械角**（取决于磁环类型，必须先实测）：

```
情况 A（2 极角度磁环）：θ_mech = θ_解算，θ_elec = θ_mech × p
情况 B（转子多极磁钢）：θ_elec = θ_解算，θ_mech = θ_elec / p（有 p 个解）
```

SVPWM 要的是**电角度**，位置环要的是**机械角**。这两个混用是新手最常见的错误——电机能转，但位置环永远不收敛。

### L4 速度

**做什么**：从角度序列估角速度。

**为什么这是本栈最脏的一层**：

```
ω = Δθ / Δt，其中 Δt = 125 µs
```

角度量化误差 1 LSB ≈ 0.09°（12 bit 有效），一次差分放大 1/Δt = 8000 倍 → 速度噪声约 12 rad/s。**这个数比云台的工作转速还大**，所以原始差分完全不能用。

三层处理：

| 措施 | 参数 | 作用 |
|---|---|---|
| 角度先低通 | 200~500 Hz | 压掉开关噪声，代价是相位滞后 |
| 差分后低通 | 100~200 Hz | 压掉量化噪声，代价是再滞后 |
| 限幅 | ±ω_max | 防止跳变时速度指令爆掉 |

**代价必须承认**：两级低通串起来，速度反馈的相位滞后可能到 2~3 ms。速度环的穿越频率就不能超过 ~50 Hz，否则相位裕度吃光。这是硬件冻结下"稳"与"快"的死结，不是调参能解决的。

**退路**：速度改用 IMU 陀螺。陀螺噪声比霍尔差分低一个量级，带宽也好，代价是丢掉电机侧信息（负载侧振动会直接进速度环）。

### L5 矢量合成（SVPWM）

**做什么**：把 uα/uβ 变成 3 路占空比。

**不要用扇区法。** 教科书上的"判断扇区 → 算 T1/T2/T0 → 七段式"代码长、边界多、容易错。用等价的**三相展开 + 零序注入**，十行就写完，且天然处理过调制：

```c
void svpwm_calc(float u_alpha, float u_beta, float vbus, float duty[3])
{
    // 1. 反 Clarke：αβ → 三相
    float ua = u_alpha;
    float ub = -0.5f * u_alpha + 0.8660254f * u_beta;
    float uc = -0.5f * u_alpha - 0.8660254f * u_beta;

    // 2. 零序注入：把三相的中点拉到母线中点
    float u_max = fmaxf(ua, fmaxf(ub, uc));
    float u_min = fminf(ua, fminf(ub, uc));
    float u_offset = -0.5f * (u_max + u_min);
    ua += u_offset;  ub += u_offset;  uc += u_offset;

    // 3. 归一化到占空比
    float inv = 1.0f / vbus;
    duty[0] = 0.5f + ua * inv;
    duty[1] = 0.5f + ub * inv;
    duty[2] = 0.5f + uc * inv;

    // 4. 限幅（保护 L0，不让它见到越界值）
    for (int i = 0; i < 3; i++) {
        if (duty[i] < 0.02f) duty[i] = 0.02f;
        if (duty[i] > 0.98f) duty[i] = 0.98f;
    }
}
```

**为什么零序注入等价于 SVPWM**：SVPWM 的电压利用率比 SPWM 高 15.5%，本质就是把零序分量（三次谐波）注入相电压，让峰值不超母线。零序注入法和扇区法数学等价，但实现短得多。

**限幅到 0.02~0.98 而不是 0~1**：给自举电容留充电时间，也避免 100% 占空比时下桥长时间关断导致电荷泵掉压。SS6343M 虽然支持 100% 占空比（有电荷泵），但留 2% 更稳。

**vbus 用常量。** 母线读数饱和（见 L2），所以 `vbus` 传 `vbus_nominal = 7.2`，不要传 ADC 读数——那会在 6.6 V 以上变成 3.6 V，占空比直接翻倍。

### L6 串级控制

**做什么**：目标角 → 电压矢量。

两层，从外到内：

```
θ_target ──►[位置 P]──► ω_target ──►[速度 PI]──► u_amp ──┐
    ▲            ▲ 限幅                     ▲             │
    │            └── ω_max                  │             ▼
θ_actual ────────────────► 误差             ω_actual    uα,uβ ──► L5
```

| 环 | 类型 | 输入 | 输出 | 限幅 |
|---|---|---|---|---|
| 位置 | P（不加 I） | 角度误差（rad） | 速度指令（rad/s） | ±ω_max |
| 速度 | PI | 速度误差（rad/s） | 电压幅值（V） | ±V_max |

**位置环为什么只用 P**：位置环加 I 会引入超调和积分饱和，云台要的是"无超调回位"，不是"零稳态误差"。重力和摩擦造成的静态偏差交给前馈（L7）补，不交给积分。

**抗饱和**（必须做，否则第一次大角度指令就会失控）：

```c
// 速度环输出饱和时，冻结积分
if (fabsf(u_vel) >= V_MAX) {
    pid_vel.integral -= pid_vel.ki * err * dt;   // 回退这一步的积分
}
```

**输出归一化**：`u_amp` 是电压（V），最后除以 `vbus_nominal` 得到 −1~+1 的归一化值，再乘 cos/sin 电角度得 uα/uβ：

```c
float u_norm = u_amp / vbus_nominal;
float theta_e = hall_get_elec(axis);
u_alpha = u_norm * cosf(theta_e);
u_beta  = u_norm * sinf(theta_e);
```

**这一句就是 FOC 的全部精髓**：把电压矢量**定向**到转子磁场方向。`theta_e` 错了，电压就打到错误的方向，表现为"电流很大但不转"或"抖动"。

### L7 前馈

**做什么**：在反馈环之外，直接算出"维持当前状态需要的电压"，让反馈环只负责修正误差。

| 前馈项 | 公式 | 参数怎么来 | 优先级 |
|---|---|---|---|
| 反电动势 | `u_ff = k_e × ω` | 转起来测：给定转速下的稳态电压 | **高**（演示版就做这个） |
| 重力 | `u_ff = (m·g·L / k_t) × sin(θ)` | 需要负载质量 m 和重心距离 L | 中（演示版可砍） |
| 摩擦 | `u_ff = u_c·sign(ω) + b·ω` | 正反低速扫描拟合 | 低 |

**为什么反电动势前馈最重要**：没有电流环，速度环的 PI 必须靠积分慢慢"追"反电动势。转速一变，积分就要重新追，动态响应被拖慢一个数量级。加上 `k_e × ω` 这一项，速度环只需要修残差，带宽立刻上一个台阶。

`k_e` 的测量方法：开环给定固定占空比让电机匀速转，记录稳态角速度和对应的电压幅值，`k_e = u / ω`。三个轴分别测，因为电机个体有差异。

### L8 保护

**做什么**：发现异常就停机，宁可停错也不能炸。

| 项目 | 判据 | 动作 | 可行性 |
|---|---|---|---|
| 堵转 | `\|u\|` 持续饱和 **且** `\|ω\| < 阈值` 超过 200 ms | 停机 | ✅ |
| 欠压 | `vbus_raw < 3700`（≈6.0 V） | 停机 | ✅ |
| 过压 | — | — | ❌ 读数饱和，做不到 |
| 过流 | — | — | ❌ nFAULT 悬空，做不到 |
| 霍尔异常 | 原始值超出 [200, 3900] | 停机 | ✅ |
| 角度跳变 | `\|Δθ\| > 阈值` 连续 3 周期 | 停机 | ✅ |

**堵转判据的写法要注意**：不能只看"电压饱和"，因为大角度阶跃时电压本来就会饱和几毫秒。必须加"且转速几乎为零"+"持续 200 ms"两个条件，否则正常动作会被误判。

### L9 标定

| 参数 | 怎么标 | 频率 |
|---|---|---|
| `pole_pairs[3]` | 转一圈数正弦周期（5 分钟，见主文档 §7.2.1） | 一次性 |
| `hall_offset[3][2]` | 转一整圈采 min/max，取中点 | 每台 |
| `hall_gain[3][2]` | 同上，取半幅 | 每台 |
| `hall_dir[3]` | 给正转看角度是否单调增，反了翻符号 | 每台 |
| `k_e[3]` | 开环匀速，`u/ω` | 每台 |
| IMU 零偏 | 静止 2 s 取均值 | 每次上电 |

**标定结果必须带版本号存 Flash**，且换负载/换电机后要重标。参数结构体的 `version` 字段不匹配时，宁可拒绝启动，也不要拿旧参数硬跑——旧参数配新硬件，飞车是分分钟的事。

## 4. 一个 125 µs 周期走一遍

给定：目标角 0.5 rad，当前 0.3 rad，vbus 7.2 V。

| 步 | 层 | 计算 | 结果 | 耗时 |
|---|---|---|---|---|
| 1 | L1 | TIM1 更新事件 → TRGO | 触发 ADC | 0（硬件） |
| 2 | L2 | DMA 搬 7 路 | raw[6] | ~9 µs |
| 3 | L3 | 归一化 → 120° 重构 → atan2 | θ_mech = 0.300 rad | ~2 µs |
| 4 | L3 | × p（设 p=7） | θ_elec = 2.100 rad | 0 |
| 5 | L4 | (0.300 − 0.298)/125µs → 低通 | ω = 12 rad/s | ~1 µs |
| 6 | L6 | pos_kp=20 × (0.5 − 0.3) | ω_target = 4.0 rad/s（未饱和） | 0 |
| 7 | L6 | vel_kp=0.05 × (4.0 − 12) + 积分 | u_amp = 0.8 V | ~1 µs |
| 8 | L7 | k_e=0.06 × 12 | u_ff = 0.72 V | 0 |
| 9 | L6 | u = 0.8 + 0.72 = 1.52 V → 归一化 | u_norm = 0.211 | 0 |
| 10 | L6 | 0.211 × cos(2.100), sin(2.100) | uα=−0.107, uβ=0.182 | ~1 µs |
| 11 | L5 | 三相展开 + 零序注入 + 限幅 | duty = {0.375, 0.505, 0.545} | ~2 µs |
| 12 | L0 | 写 3 个 CCR | — | ~1 µs |

**合计约 17 µs，占 125 µs 的 14%。** 预算表里写的 32% 是按最坏情况（atan2 走软件库、浮点未开 FPU）估的，实际开 FPU 后更宽裕。

**注意第 7 步和第 9 步**：速度环算出来是 0.8 V，但当前转速 12 rad/s 意味着反电动势要 0.72 V，所以实际加在电感上的只有 0.08 V——这就是前馈的作用，让 PI 从"追大数"变成"修小数"。

## 5. 与标准 FOC 的对照

| 环节 | 标准 FOC | 本栈 | 差在哪 |
|---|---|---|---|
| 角度 | 编码器 / 观测器 | 2 路线性霍尔 120° 重构 | 精度低，噪声大 |
| Clarke | 三相电流 → iα/iβ | **不做** | 无电流采样 |
| Park | iα/iβ → i_d/i_q | **不做** | 同上 |
| 电流 PI | i_d=0, i_q=给定 | **不做** | 同上 |
| 反 Park | u_d/u_q → uα/uβ | **不做** | 无电流环，直接给电压矢量 |
| SVPWM | 有 | **有** | 保留 |
| 死区 | 需配置 + 补偿 | **芯片内部做** | 省一层 |
| 外环 | 位置 / 速度 | 位置 P + 速度 PI | 保留 |
| 前馈 | 可选 | **必需** | 无电流环，动态全靠它 |

**结论：这是"电压模式 FOC"——保留了磁场定向和 SVPWM 的骨架，砍掉了整个电流环。** 严格讲不满足教科书 FOC 的定义（没有 i_d/i_q 闭环），但云台负载恒定、转速低、不需要弱磁，这个简化是硬件逼出来的唯一选择，也是够用的选择。

## 6. 逐层验证顺序

**不要跳层。** 每一层单独验证通过，再上下一层。这是 M2/M3/M4 三个里程碑的实际内容。

| 层 | 怎么单独验 | 通过标准 | 里程碑 |
|---|---|---|---|
| L0 | 示波器看三相 PWM | 24 kHz，三相互补，无窄脉冲 | M1 |
| L1 | 示波器看 TRGO / ADC 触发 | 8 kHz，间隔抖动 < 100 ns | M1 |
| L2 | 串口打印 7 路原始值 | 霍尔在 200~3900 之间随转动变化 | M1 |
| L3 | 手动转一圈打印角度 | 0→360° 连续，无跳变，误差 < 1° | **M2** |
| L4 | 匀速转，打印速度 | 正反转符号正确，噪声 < 5 rad/s | M2 |
| L5 | 给定固定 uα/uβ，看占空比 | 六扇区波形正确，限幅生效 | M3 |
| L6 | 闭环，手拨轴 | 能回位，无自激，无超调 | **M4** |
| L7 | 加前馈前后对比跟随误差 | 快速摆动时误差降低 40% | M6 |
| L8 | 人为堵转 / 拉低母线 | 200 ms 内停机 | M8 |

**L3 是分水岭。** 它同时验证了霍尔接线、120° 公式、归一化、符号四件事。L3 不过，L5/L6 写了也是白写——因为 SVPWM 的角度输入是错的，电机只会抖不会转。

## 7. 最容易踩的五个坑

| # | 坑 | 症状 | 原因 |
|---|---|---|---|
| 1 | 忘了拉高 nSLEEP | PWM 有波形，电机纹丝不动 | 芯片还在睡眠，EN 上拉不代表芯片醒着 |
| 2 | 机械角当电角度用 | 电机能转，位置环永不收敛 | SVPWM 要 θ_elec = p × θ_mech |
| 3 | `hall_dir` 符号反了 | 手一拨就飞车 | 位置环变正反馈 |
| 4 | vbus 传了 ADC 读数 | 占空比突然翻倍，电机啸叫 | 母线读数 6.6 V 以上饱和在 4095 |
| 5 | PWM 通道按 CH1/2/3 顺序写 | 某一轴转向反，或三相不平衡 | M1/M3 的通道是倒序的，必须表驱动 |

第 3 条最危险——它不会报错，只会让电机瞬间冲到限位。**调试时第一次闭环务必用限流电源或串一个功率电阻**，别直接用电池。

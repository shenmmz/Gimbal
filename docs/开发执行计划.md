## 2. W1 开工前必须完成的三件事

这三件事**只要半天**，但不做则 W3 之后全部白干。所以压在 W1 的头两天。

| # | 事项 | 怎么做 | 耗时 | 不做的后果 |
|---|---|---|---|---|
| 1 | **霍尔读的是哪种磁环** | 手动转一圈，示波器看一路霍尔数正弦周期：1 个 = 2 极磁环；p 个 = 转子磁钢（顺便得极对数） | 5 分钟 | 情况 B 下机械角有 p 个解，架构要改 |
| 2 | **两路相位差是不是 120°** | 双通道示波器量两路上升沿时间差 ÷ 周期 × 360° | 10 分钟 | 若为 0° 则 atan2 失效，方案不成立 |
| 3 | **M1/M2/M3 对应哪根轴** | 查板子丝印 / 看装配关系 / 转一下看哪个轴动 | 30 分钟 | 轴映射错，自稳方向反，直接失控 |

**第 1 和第 2 项是同一个测量**，一起做。详细判据见《云台固件架构设计》§7.2.1。

另外两件可以并行做、不阻塞编码的事：

| 事项 | 找谁 | 什么时候要 |
|---|---|---|
| 相机重量、重心位置、机械接口图纸 | 相机方 | **W6 之前**（M4 调参要用配重块） |
| 配重块制作（轻/标称/重三块） | 机加工 | W6 之前到货 |

## 4. 逐周详细计划

### W1 · 10-26 ~ 11-01 · M0 板级自检

**本周唯一目标：确认三块板都是活的，别在坏硬件上写一周代码。**

技术栈：L0（PWM 引脚）、L2（ADC）

| 天 | 任务 | 产出 |
|---|---|---|
| D1 上午 | 三块板目检：短路、虚焊、器件方向；万用表测 +7V / +3.3V 对地阻抗 | 阻抗记录 |
| D1 下午 | 上电：先只给 VDD，测 +7V、+3.3V、V3P3（驱动板本地 LDO） | 电压记录表 |
| D2 | **完成 §2 的三个前置测量**（霍尔周期、相位差、轴映射） | 结论写进本文 §2 |
| D3 | 建工程骨架：时钟树 168 MHz、串口 115200、`printf` 重定向 | 能打印 |
| D4 | nSLEEP 拉高（PC10/PA11/PA12），PWM 固定 50% 占空比，示波器看 9 路 | 波形截图 |
| D5 | ADC1 扫描 7 通道 + DMA，串口打印原始值 | 数据表 |
| D6 | 手动转每个轴，记录霍尔原始值的 min/max 范围 | 范围表 |
| D7 | 补漏 + 整理基线数据 | 基线文档 |

**验收标准（全中才算过）**：

- [ ] 三块板 +7V、+3.3V 都在 ±5% 内
- [ ] 9 路 PWM 都有 24 kHz 波形，三相互补关系正确
- [ ] 7 路 ADC 都有读数，且霍尔值随转动变化
- [ ] 霍尔原始值落在 200~3900 区间内（超出说明磁隙或偏置有问题）
- [ ] 三个 nSLEEP 引脚都能拉高（示波器确认电平）

**卡点**：如果某块板的 PWM 没波形，先查 nSLEEP 有没有真的拉高，再查 EN 是否上拉到位（EN 是硬件上拉，量一下电压应该是 3.3 V）。

**风险**：板子是定型产品，坏板只能返修。**W1 发现问题是最幸运的**，越往后发现代价越大。

### W2 · 11-02 ~ 11-08 · M1 三轴 PWM 打通

**本周唯一目标：三轴 PWM 严格同步、ADC 由硬件触发、时序可复现。**

技术栈：L0、L1、L2

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | TIM1 配置为中心对齐 24 kHz（ARR=6999, PSC=0），三路 CH 输出 | TIM1 波形 |
| D2 | TIM3/TIM4 配置为从模式，由 TIM1 TRGO 触发，三相同步启动 | 三轴同步波形 |
| D3 | 验证 PWM 通道映射表（**M1/M3 是倒序的**，必须表驱动） | 映射表代码 |
| D4 | RCR=2 使更新事件 8 kHz，TRGO 触发 ADC | 8 kHz 触发波形 |
| D5 | 测触发抖动（示波器余辉看 TRGO 边沿） | 抖动 < 100 ns |
| D6 | ADC 采样时间调优：霍尔通道短、母线通道长 | 采样配置 |
| D7 | 写 `pwm_set_duty()`，三相同一周期生效（预装载） | 接口完成 |

**验收标准**：

- [ ] 三轴 PWM 频率都是 24 kHz，相位一致（同时启动）
- [ ] 给定 duty = {0.3, 0.5, 0.7}，示波器读出的占空比误差 < 1%
- [ ] TRGO 稳定 8 kHz，抖动 < 100 ns
- [ ] ADC 转换完成中断频率 = 8 kHz
- [ ] 母线通道读数与万用表测的母线电压对得上（< 6.6 V 时）

**卡点**：如果三轴 PWM 不同步，检查从定时器的触发源是否配成 ITR0（TIM1），而不是软件触发。

### W3 · 11-09 ~ 11-15 · M2 角度解算

**本周唯一目标：角度能算出来，且转一圈是连续的。**

技术栈：L3

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | `hall.c` 骨架：偏置/增益归一化（先用 W1 采的 min/max 硬编码） | 归一化后的 va/vb |
| D2 | 120° 重构：`cosθ = -(vb + 0.5·va) × 1.1547005` | sin/cos |
| D3 | `atan2f` 解算 + 角度展开（−π~+π → 连续 0~2π） | 连续角度 |
| D4 | 手动转一圈，串口打印角度，画出来看 | 曲线 |
| D5 | 定 `hall_dir` 符号（正转看角度是否单调增） | 符号确定 |
| D6 | 加一阶低通（200~500 Hz），对比加滤波前后噪声 | 噪声数据 |
| D7 | 电角度换算（× 极对数），验证 SVPWM 输入 | θ_elec |

**验收标准**：

- [ ] 手动匀速转一圈，角度单调变化，**无跳变、无回头**
- [ ] 0→360° 覆盖完整，起止点衔接平滑
- [ ] 静止时角度抖动 < 0.3°（滤波后）
- [ ] `hall_dir` 符号确定，正转角度增大

**卡点**：角度有 2 次周期波动（一圈起伏两次）→ 归一化的偏置或增益没标对。角度有 p 次波动 → 磁钢多极，情况 B。

**这一周是整个项目的分水岭。** 角度不对，后面全白做。

### W4 · 11-16 ~ 11-22 · M2 标定与验收

**本周唯一目标：把 W3 的硬编码换成标定流程，精度压到 1° 以内。**

技术栈：L3、L9

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | `calibration.c`：转一圈采 min/max | 标定状态机 |
| D2 | 标定结果写 Flash，带版本号 | 参数持久化 |
| D3 | 三轴分别标定，对比三轴参数差异 | 参数表 |
| D4 | 用外部基准（量角器/光学平台）比对绝对精度 | 误差数据 |
| D5 | 若误差 > 1°，查：磁隙不均、霍尔非线性、ADC 参考电压 | 误差归因 |
| D6 | 速度估计（L4）：差分 + 两级低通，测噪声 | 速度噪声数据 |
| D7 | M2 验收 + 写标定作业指导 | 验收报告 |

**验收标准**：

- [ ] 三轴标定后，全圈最大误差 < 1°
- [ ] 标定结果断电不丢
- [ ] 速度估计正反转符号正确，噪声 < 5 rad/s（滤波后）
- [ ] **转一圈霍尔只有 1 个正弦周期**（确认情况 A）

**卡点**：如果速度噪声怎么滤都大于 10 rad/s，说明霍尔信噪比不够。这时先不要硬上速度环，考虑《架构设计》§13.2 的退路 3（速度改用 IMU 陀螺）。

### W5 · 11-23 ~ 11-29 · M3 开环旋转

**本周唯一目标：电机能平滑转起来，不抖不叫。**

技术栈：L5

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | `svpwm.c`：反 Clarke 三相展开 | ua/ub/uc |
| D2 | 零序注入 + 归一化 + 限幅（0.02~0.98） | 3 路占空比 |
| D3 | 开环测试：固定电角度，给定电压矢量，看电流（用电源电流表） | 静态矢量验证 |
| D4 | 开环旋转：电角度按固定斜率递增 | 电机转起来 |
| D5 | 调转速、看噪音、测空载电流 | 空载特性 |
| D6 | 验证三相相序（**转向反了就换任意两相**） | 相序确定 |
| D7 | 观察不同占空比下的启动特性 | 启动阈值 |

**验收标准**：

- [ ] 给定固定电压矢量，电机保持不动（有保持力矩）
- [ ] 电角度匀速递增，电机平滑旋转，无卡顿、无异常噪音
- [ ] 空载电流在合理范围（几十 mA 到 200 mA）
- [ ] 三相相序确定，正转方向符合预期

**卡点**：电机抖动不转 → 相序错，或电角度方向反（`hall_dir` 符号）。电机转但噪音大 → PWM 频率或死区问题（死区是芯片内部的，查不了，只能看波形）。

**W5 后半段就可以开始试闭环了**，不用等"完美开环"。

### W6 · 11-30 ~ 12-06 · M4 单轴闭环初调

**本周唯一目标：单轴能锁住，哪怕会抖。**

**前置：配重块必须到货。空载调参等于白调。**

技术栈：L6

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | 装配重块，测转动惯量（或用摆法估） | 惯量估值 |
| D2 | `pid.c`：位置式 PID + 积分限幅 + 输出限幅 + 抗饱和 | PID 模块 |
| D3 | `axis.c`：位置 P → 速度 PI → 电压，先只开位置环 | 位置环 |
| D4 | 位置环调参：从小 kp 开始，逐步加大到临界振荡再退一半 | pos_kp |
| D5 | 加速度环，速度环从"很小"开始 | vel_kp/ki |
| D6 | 手拨测试：拨开能不能回位、回位有没有超调 | 响应曲线 |
| D7 | 记录振荡频率，判断是机械共振还是控制自激 | 频谱 |

**验收标准**：

- [ ] 手拨开后能回原位（允许超调）
- [ ] 静止时没有持续的高频抖动
- [ ] 没有"嗡嗡"的低频自激

**卡点（这是全项目最难的一周）**：

| 现象 | 判断 | 处理 |
|---|---|---|
| 高频啸叫（> 500 Hz） | 控制增益过高 | 降 kp |
| 低频摆动（1~10 Hz） | 相位滞后太大 | 降速度环带宽，或减滤波 |
| 回位后慢慢漂走 | 静摩擦力 | 加一点积分或摩擦前馈 |
| 一碰就飞车 | **符号反了** | 立刻断电，查 `hall_dir` |

**安全**：第一次闭环务必用**限流电源**（限流 1 A）或串功率电阻，别直接上电池。飞车时至少不会烧。

### W7 · 12-07 ~ 12-13 · M4 单轴锁定 ★

**本周唯一目标：从"能锁"到"锁得稳"。这是决定性里程碑。**

技术栈：L6、L7（反电动势前馈提前上）

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | 系统辨识：给阶跃，记录响应，估自然频率和阻尼 | 响应曲线 |
| D2 | 按辨识结果重调参数（不要盲试） | 参数组 |
| D3 | 加反电动势前馈 `u_ff = k_e × ω`，测 `k_e` | k_e 值 |
| D4 | 前馈前后对比跟随误差 | 对比数据 |
| D5 | 长时间静止测试：看漂移、看温升、听噪音 | 30 分钟数据 |
| D6 | 极限测试：最大角度阶跃、最大速度 | 边界数据 |
| D7 | **M4 验收 + 参数存档** | 验收报告 |

**验收标准（M4 过关线）**：

- [ ] 手拨 30° 后 500 ms 内回到原位，超调 < 10%
- [ ] 静止 10 分钟，角度漂移 < 0.5°
- [ ] 无持续抖动、无自激
- [ ] 连续运行 30 分钟，电机外壳温升 < 30 K

**这一周过了，项目就成功了一半。** 它同时证明霍尔解算、SVPWM、PID 三件事都对。

**如果 W7 结束还没锁住**：按《架构设计》§13.2 的三条退路依次试——① `pos_kp` 减半 ② 去掉速度环 ③ 速度改用 IMU 陀螺。三条都不行就砍 M6，直接进 M5。

### W8 · 12-14 ~ 12-20 · M5 三轴闭环

**本周唯一目标：三个轴同时锁，互不干扰。**

技术栈：L6

| 天 | 任务 | 产出 |
|---|---|---|
| D1 | `gimbal.c`：轴映射表 + 三轴调度 | 三轴框架 |
| D2 | 三轴逐个使能，观察相互影响 | 耦合数据 |
| D3 | 处理轴间机械耦合（一个轴动，另一个轴受扰） | 解耦策略 |
| D4 | 三轴同时阶跃测试 | 同步响应 |
| D5 | 三轴独立标定参数对比（每轴参数不同） | 参数表 |
| D6 | 整机静态锁定测试 | 30 分钟数据 |

## 6. 并行任务线

三条线可以并行，不占用主开发时间：

| 线 | 任务 | 谁做 | 时间要求 |
|---|---|---|---|

## 7. 三个检查点与兜底

| 检查点 | 必须拿到 | 没拿到怎么办 |
|---|---|---|
| **W5 末** | 电机开环平滑旋转 | **停手查硬件**：相序、霍尔装角、nSLEEP、驱动使能。不要往下写闭环代码 |
| **W7 末** | 单轴稳定锁定 | ① `pos_kp` 减半 ② 去掉速度环 ③ 速度改 IMU 陀螺。三条都不行 → 砍 M6 直接进 M5 |
| **W8 末** | 三轴独立锁定 | 只交付单轴演示，另两轴机械锁定。**不要为了"三轴都动"牺牲稳定性** |

**兜底的共同原则：砍功能，不延期。** 13 周的承诺是"能演示"，不是"全部做完"。演示少一个动作没人会追究，延期交付才是问题。
